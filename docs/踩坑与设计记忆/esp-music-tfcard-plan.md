## 1. 硬件事实（不要重新推导）

| 项 | 值 | 出处 |
|---|---|---|
| 旋转编码器 | HYCW03-2.8D-5P-S，增量式 **12 节点/12 脉冲**，带按压 | `pcb/bom_dump.txt` |
| `ENC_A` / `ENC_B` / `ENC_SW` | `IO9` / `IO10` / `IO11` | `pcb/接线表与引脚定义.md` |
| 编码器上拉 | A/B/SW 各 **10k 外部上拉**（R18/R19/R20）；A/B 另有 100nF 到地（C26/C27） | 同上（引脚网络逐个核对过） |
| 极性 | 公共端接地 → **低电平有效**（与 K1-K4 一致） | 同上 |
| `TF_CS` / `TF_MISO` / `TF_CD` | `IO12` / `IO13` / `IO14` | 同上 |
| TF 与屏幕 | **共用 SPI2**：CLK=IO4、MOSI=IO5，靠 CS 区分（屏 IO15 / 卡 IO12） | 同上 |
| TF 模式 | DAT1/DAT2 悬空 → **只能 SPI 模式**，不是 SD 1-bit | 同上 |
| 屏幕型号 | **同款** M180-128160（ST7735S），只是从 8 针排针模块换成 14PIN FPC | `pcb/资料/设计规格书/README.md` |

**结论：屏幕与 ES8388 的驱动代码不需要重写**（同控制器、同引脚、同 I2C 地址）。
只有三处数值要真机重校 —— 见 dev record 第 7 节的清单（屏幕批次色序/偏移、SPI 40MHz、
耳放直推后的音量曲线）。

### ⚠️ 电量显示做不到
IP5306 直接驱动 3 颗 LED，**没有任何一路回到 ESP32**。要显示电量必须重新打板加 ADC 分压。
**不要再为此找软件方案。**

## 2. 用户已拍板的决定（别再问）

- 要**无损**不要转码；离线模式也走本地原文件直出。
- TF 卡用途是**离线曲库**（不是在线缓存 —— 在线缓存继续留 flash 的 `cache` 分区）。
- 编码器当**全菜单方向键**，并且**接替列表/菜单页 K1/K2 的"选择"角色**；
  **K1/K2 的语义不删**（面包板上它们是唯一入口）。
- **在线与离线的曲库、歌单、收藏、最近播放全部分开**。
- 在线模式下要能**一键把收藏同步到离线**：能匹配上的同步，匹配不上的跳过（**只同步标记，不下载音频**）。
- **断点续播不要了**；**菜单里不要音质选项**（固定最高）；**BLE 可以砍**（已砍）。

## 3. 方案要点（实施时的取舍）

1. **一份代码两种板型**：`CONFIG_BOARD_VARIANT_BREADBOARD` 是唯一真相源，
   `BOARD_HAS_ENCODER`/`BOARD_HAS_TF` **由它派生**（不是各自一个 Kconfig bool ——
   sdkconfig 里写进过值之后 default 就不再跟着板型求值了）。
2. **SPI 总线不用大改**：`esp_vfs_fat_sdspi_mount()` 只要求总线已初始化，
   而屏幕在开机第 3 步就建好了。只需把 `spi_bus_initialize` 换成幂等的
   `board_spi_bus_init()`，**零时序变化** —— 原方案里"高风险"的那一项因此消失。
3. **SD 懒挂载 + 用完卸载**：内部 SRAM 起播后只剩 10~15KB，SDSPI/SDMMC 要用内部 RAM。
   在线模式不该被用不到的驱动占着。
4. **必须开 FATFS 长文件名 + UTF-8 API**：卡上是用户的音乐，非 LFN 下长名是**打不开**
   而不是截断。用 `LFN_HEAP` + `ALLOC_PREFER_EXTRAM` → LFN 缓冲走 PSRAM，不吃内部 SRAM。
5. **曲库索引放卡上**（`/sdcard/ESP-MUSIC.IDX`），常驻 PSRAM（约 374B/首，2000 首 ≈ 744KB）。
   用头部 CRC 校验代替"写 TMP 再改名"的原子写 —— 索引可重建，校验不过就当没有。
6. **元数据来自文件名**（用户确认）：`艺术家 - 标题.ext`，第一个 `" - "` 切分。
   不解析标签 → 离线时长在首次播放前未知。
7. **离线搜索不需要拼音索引**：屏上拼音输入法输出的已经是汉字，只做 UTF-8 子串匹配。
8. **绝不格式化用户的卡**：`format_if_mount_failed = false`，只写索引那一个文件。
