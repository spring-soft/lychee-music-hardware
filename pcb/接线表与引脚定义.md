# ESP-Music PCB —— 接线表与引脚定义

**板子**：58.0 × 50.0 mm，四层板　　**工程**：嘉立创EDA专业版 `esp-music-player`

> 本文件由 PCB 实际网络数据生成（数据源 `pads.raw.json`，导出自 EDA）。
> ESP32 引脚号↔GPIO 名取自原理图符号 `ESP32-S3-WROOM-1-N16R8`，权威。

### 已用引脚汇总（按功能分组）

- **音频（I2S → ES8388）**：脚32=IO39→`I2S_LRCK`　脚33=IO40→`I2S_DOUT`　脚34=IO41→`I2S_BCLK`　脚35=IO42→`I2S_MCLK`　脚38=IO2→`I2C_SCL`　脚39=IO1→`I2C_SDA`
- **屏幕（SPI → ST7735S）**：脚4=IO4→`LCD_SCLK`　脚5=IO5→`LCD_MOSI`　脚6=IO6→`LCD_RST`　脚7=IO7→`LCD_DC`　脚8=IO15→`LCD_CS`　脚9=IO16→`BL_DRV`
- **按键**：脚31=IO38→`KEY_K1`　脚12=IO8→`KEY_K2`　脚11=IO18→`KEY_K3`　脚10=IO17→`KEY_K4`　脚27=IO0→`BOOT_N`　脚3=EN→`RESET_N`
- **旋转编码器**：脚17=IO9→`ENC_A`　脚18=IO10→`ENC_B`　脚19=IO11→`ENC_SW`
- **USB（原生）**：脚13=IO19→`USB_DN`　脚14=IO20→`USB_DP`
- **电源**：脚2=3V3→`VCC`　脚1=GND→`GND`　脚40=GND→`GND`　脚41=GND/EP→`GND`

### ⚠️ 必须悬空的引脚

| 脚号 | GPIO | 原因 |
|---:|---|---|
| 28 | IO35 | **N16R8 的 Octal PSRAM 内部占用，接任何东西都会导致无法启动** |
| 29 | IO36 | 同上 |
| 30 | IO37 | 同上 |
| 15 | IO3 | strapping 脚（本板已刻意避开，故 K1 从 IO3 改到 IO38） |
| 16 | IO46 | 规格书未用 |
| 20–26 | IO12/13/14/21/47/48/45 | 规格书未用 |
| 36, 37 | RXD0/TXD0 | 默认串口，留作调试焊盘 |

> ⚠️ 网上大多数 ESP32-S3 例程用的是 **N8R2（Quad PSRAM）**，那三根 IO35/36/37 可以随便用。
> **本板是 N16R8，照抄会直接无法启动。**

## 三、电源树

```
Type-C VBUS (5V)
   │
   ├─→ C21, C22 (滤波)
   └─→ U4 IP5306 VIN
            │  （充电 + 升压 + 电源路径管理）
            ├─→ BAT+ ─→ J4 电池座 ─→ 锂电池 3.7V
            ├─→ L1 (2.2µH) ─→ SW_NODE （开关节点）
            └─→ +5V  ──┬─→ C23, C24 (滤波)
                        ├─→ U3 TLV75733 LDO IN
                        ├─→ R12 → LED_A  （屏幕背光）
                        └─→ R15/R16/R17 → LED1-3_R （电量灯）
                                 │
                        U3 LDO OUT ─→ VCC (3.3V)
                                 ├─→ U1 ESP32-S3 (脚2)
                                 ├─→ U2 ES8388 (脚2,3,26)
                                 ├─→ J3 屏幕座 (脚10,11)
                                 └─→ 各上拉电阻 / 退耦电容
```

| 轨 | 电压 | 来源 | 主要负载 |
|---|---|---|---|
| `VBUS` | 5V | Type-C | IP5306 充电输入 |
| `BAT+` | 3.0–4.2V | 锂电池 | IP5306 升压输入 |
| `+5V` | 5V | IP5306 升压输出 | LDO、背光、电量灯 |
| `VCC` | 3.3V | TLV75733 LDO | ESP32、ES8388、屏幕 |
| `AVDD` | 3.3V | VCC 经 FB1 磁珠 | ES8388 模拟部分 |
| `HPVDD` | 3.3V | VCC 经 FB2 磁珠 | ES8388 耳机功放 |

**已删除的宏**（自制板不适用）：

- `BOARD_PIN_I2S_DIN` —— 不录音，ES8388 ADC 已断电，I2S 通道是 TX-only
- `BOARD_PIN_PA_EN` —— 已去掉 PAM8406 功放，ES8388 内置耳放直推耳机

> ⚠️ `BOARD_PIN_KEY1` 从 **GPIO3 改到了 GPIO38**（避开 strapping 脚）。
> **不打固件补丁就烧录，K1 会直接失效**（固件轮询悬空的 IO3，永远读到"未按下"）。
> 补丁见 `firmware-patch.diff`。

**ES8388 I2C 地址**：`0x11`（7 位）＝ `0x22`（8 位）。由 `CE` 脚接 VCC 决定。
