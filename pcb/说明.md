# ESP-Music PCB · 项目说明

**板子**：58.0 × 50.0 mm 四层板　　**DRC**：0 违规　　**工程**：嘉立创EDA专业版 `esp-music-player`

---

## 📤 要上传给嘉立创的三个文件

| 文件 | 用途 | 上传到哪 |
|---|---|---|
| **`① Gerber_打样用.zip`** | PCB 打样 | 嘉立创「PCB 下单」→ 上传 Gerber |
| **`② SMT_BOM元件清单.xlsx`** | SMT 贴片 | 嘉立创「SMT 贴片」→ 上传 BOM |
| **`③ SMT_贴片坐标.xlsx`** | SMT 贴片 | 嘉立创「SMT 贴片」→ 上传坐标文件 |

### 下单参数建议

| 选项 | 选 |
|---|---|
| 层数 | **4 层** |
| 板厚 | **1.6 mm** |
| 铜厚 | **外层 1oz / 内层 0.5oz**（默认，别改） |
| 材质 | **FR-4** |
| 表面处理 | 沉金（推荐）或喷锡（免费） |
| 阻焊颜色 | 随便挑（哑黑+沉金最好看，绿色免费） |
| 最小线宽/线距 | 常规档（本板最细 0.21mm，不用加钱） |
| 层压顺序 | **顶层 → 内层一(VCC) → 内层二(GND) → 底层** |

## ⚠️ 三件事必须记住

### 1. 固件补丁必须打

`firmware-patch.diff` 把 `BOARD_PIN_KEY1` 从 **GPIO3 改到 GPIO38**。
不打补丁就烧录，**K1 按键会直接失效**（固件轮询悬空的 IO3，永远读到"未按下"）。

```bash
patch -p1 < firmware-patch.diff
```

### 2. IO35 / IO36 / IO37 绝对悬空

本板是 **N16R8**（Octal PSRAM），这三个脚被 PSRAM 内部占用。
网上例程多是 **N8R2**（Quad PSRAM）版本，那三根能用 —— **照抄会直接无法启动**。

### 3. ES8388 的 CE 脚必须接 VCC

决定 I2C 地址（CE=1 → **0x11**，正是固件用的）。接错芯片完全无响应。

## 🔧 用接口驱动 EDA（下次改板用）

```bash
# 1. 启动桥接服务（需 EDA 已打开并连接）
node ~/.claude/skills/easyeda-api/scripts/bridge-server.mjs

# 2. 执行脚本
cd 工具 && node eda.mjs dump-pads.js
```

**已知接口坑**（详见 `交付说明-PCB布线.md` 第八节）：

- **改完必须 `await eda.pcb_Document.save()`** —— 不保存的接口改动一刷新就回退
- 工程里可能有多个 PCB 文档，`getAllPcbsInfo()[0]` 顺序会变，**要用 uuid 锁定**
- `autoRouting()` 接口调用后永不返回（界面点按钮正常）
- 铺铜填充**必须在界面点「重建铺铜」**
- 移动元件**会清空全部走线**，布局微调必须在布线之前做完
